# inbox

Put song files here: **MIDI** (`.mid`, `.midi`, `.kar`), **MusicXML** (`.musicxml`, `.xml`, `.mxl`) or
**MuseScore** (`.mscz`). On GitHub: **Add file → Upload files**, then **Commit changes**.

A couple of minutes later each file has moved to `library/<song>/` and the song is in `catalog/`, ready in the app.
`catalog/report.md` says what happened to each file.
